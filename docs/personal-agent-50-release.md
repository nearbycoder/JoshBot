## Shared boundaries

State quotas measure serialized **UTF-8 bytes**. New-feature caps are **48 KiB**, or **64 KiB** for the specified text-heavy features; admission uses a margin plus worst-case mandatory lifecycle projection. The fixed margin alone is not proof of lifecycle capacity. Complete record export, including its envelope, is bounded at **24 KiB**; normal replies at **3,500 JavaScript string units**. Count limits can be reached after byte limits; each guide remains authoritative for its exact counts, parser bounds, paging and erasure behavior.

Runtime admission defaults to **three global** and **two per workspace/user** invocations with immediate busy rejection, using one **120-second deadline** across phases. Pending physical work retains its permit. Cancellation cannot undo an already dispatched CAS or guarantee provider billing stops. These are bounded execution semantics, not promises of rollback or external side effects being reversed.

Source reads allow at most **2,000 items / 16 MiB per read**, **32 MiB total** and **eight reads** per invocation; lower feature budgets still apply. The complete-kind helper makes at most **six sequential groups** without exceeding the same limits. Capacity errors require the documented source narrowing/recovery steps rather than silent truncation, retries in chunks or global source caches. There are no global source caches.

Connected context includes private toolbox records, confirmed calendar imports and eligible approved memory cards. Legacy follow-ups, reminders, monitors and digests are scoped to owned records in the **signed current channel**. Saved artifacts and legacy personal memory are unconnected; legacy memory import has no candidates. Home discovery has no channel/source execution, and a missing reference does not prove deletion. See the [source contract](agent-features/context.md); command-specific source sets and narrowing errors remain unchanged in each guide.
