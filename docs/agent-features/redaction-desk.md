# Redaction desk

Implemented locally; **unregistered and not deployed**. Parent integration owns metadata/lazy registration and release. Prefix commands with `/nobo-help agent redaction-desk`; `help` lists all syntax without state or service reads.

`create Shareable note | Contact Maya at maya@example.com about the launch.` saves an original and current version. Copy the returned ID into `scan DOC | email`, then `preview DOC TOKEN`. The preview shows exact matched text, zero-based UTF-16 offsets (end exclusive), selected spans and the proposed current text. `apply DOC TOKEN` replaces selected spans with `[EMAIL]`, `[PHONE]`, `[LITERAL]` or `[MIXED]`, consumes that preview and retains one prior version. `undo DOC` restores that retained version and consumes undo/preview. No text is sent anywhere. Copying or applying never establishes that all secrets were found.

`scan DOC | email,phone,literal` enables the selected categories and makes a fresh token. `settings DOC | email,phone,literal` changes categories without scanning; `none` disables all. Categories are bounded email/phone heuristics and case-sensitive exact literals from `literal DOC add sensitive text`. `literal DOC edit LITERAL | sensitive text` replaces a literal; `remove DOC literal LITERAL confirm` removes it. Full literal IDs are in show/export. At most twenty literals of 300 units each are retained.

The email heuristic inspects bounded ASCII email-like tokens/local/domain labels; the phone heuristic considers bounded 7–15-digit runs with common separators. Neither understands every valid international address/number; phone-like dates/identifiers may be false positives, and names/credentials are not inferred. Literal matching supports overlapping occurrences. Fixed-size difference arrays merge overlapping intervals without allocating every match or using catastrophic regexes. Touching intervals remain separate. Merged spans keep the union of their categories; multiple categories use `[MIXED]`. At most thirty merged spans are accepted; larger scans reject entirely, asking you to narrow categories/literals or revise the text. No hidden omitted tail is marked safe.

`select DOC TOKEN | 1,3` changes selected span numbers (`none` selects none), increments the revision and returns a **new token**. Reopen the new preview before applying. Re-scans, any edit/removal, undo or apply invalidate old tokens. Selection bounds, exact recalculated spans, revision and token are validated again on every CAS retry. Concurrent edits/deletions win; an old apply cannot overwrite or resurrect them. Replayed tokens cannot apply twice. A zero-match/empty-selection apply is still explicit and retains the one prior version.

`revise DOC | current text`, `original DOC | original text`, and `title DOC | title` edit their accepted fields independently. Manual edits preserve the existing undo version; inspect it before restoring. A later apply explicitly replaces that one undo version. `clear DOC original|current|undo|preview|literals|settings confirm` clears the chosen field and invalidates any preview. `delete DOC confirm` removes original/current/undo and all configuration; without confirmation, delete only displays the confirmation command. **Original, literals and undo may still contain secrets until explicitly cleared/deleted.** There is no hidden history, eviction or expiry.

`list [page]` shows all six possible documents, preview/undo status and usage. `show DOC [page N] [rev N]` exposes every retained field; `copy` uses that suffix to return only current text, with an incomplete-detection notice. `preview DOC TOKEN [page N] [rev N]` is losslessly paginated with its exact token and revision. Next commands reject changed records. `export DOC` returns the entire JSON feature/version envelope, including original/undo/literals/preview, within 24,576 UTF-8 bytes. Pipe fields trim outer whitespace and decode `\|`/`\\`; accepted text is preserved and plaintext replies are not mrkdwn-escaped twice.

The sole `state` value is strict schema version 1. Limits: six documents, 6,000 units/16,000 UTF-8 bytes per original/current/undo text, twenty literals, thirty spans, one preview and one undo. Serialized state admits new content below 49,152 bytes and all lifecycle states below 65,536 bytes; each full exported root stays within 24,576 bytes. Copies/Unicode/JSON escaping can reach byte limits before nominal text/count limits. Admission conservatively projects a full undo copy, thirty maximum-size preview spans/selection, two 270-byte replacement-growth allowances and maximum revision widths for every root. For saved previews it also validates exact apply/undo results and the sum of each record's largest reachable state, covering mixed application order. A masked output exceeding text limits rejects the scan/selection before saving; reduce the input or matching rules. Every accepted preview has room for apply/undo, including all other pending previews. Complete show/copy/preview rendering is verified before admission.

Quota failures leave data intact; use list, export and confirmed deletion to free capacity. Malformed state, forged spans/selection or inconsistent revisions fail without overwriting, including on delete; a maintainer must repair that scoped state, while help stays usable. All transforms are synchronous and pure with IDs/tokens generated before CAS. The shared actual runtime provides owner isolation, receipts, inherited deadline/cancellation; an already dispatched CAS cannot be rolled back, so inspect an uncertain save before repeating. Metadata budgets exactly match the catalog: zero generations/searches/context reads, eight logical reads, four updates. Commands use one read and at most one update; no external actions, timers or retained caches.

Verification: eight tests in `tests/agent-redaction-desk.test.ts` use the real runtime/store fixture with throwing services. They cover the catalog, overlap/touching spans, phone/email Unicode offsets, selected tokens, all field edits/removals, thirty-span rejection and overlapping floods, full escaped Unicode retrieval, near-capacity scan/apply/undo for all accepted roots, corrupt previews/owner isolation and actual CAS edit/delete conflicts.
