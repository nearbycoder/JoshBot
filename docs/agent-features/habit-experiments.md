# Habit design experiments

Implemented locally; **not registered or deployed**. Parent integration owns registration, independent review and release.

Start `/nobo-help agent habit-experiments create Reading cue | Put the book beside the kettle`. Prefix subsequent commands with `/nobo-help agent habit-experiments`; replace `EXPERIMENT` with the returned full ID.

- `habits EXPERIMENT` reads only owned habits once and returns source IDs/fingerprints. `attach EXPERIMENT | HABIT_SOURCE [| FINGERPRINT]` explicitly selects a current source; the optional displayed fingerprint rejects a changed source. Reattach replaces the selection and invalidates dependent evidence.
- `windows EXPERIMENT | BASELINE_START | BASELINE_END | INTERVENTION_START | INTERVENTION_END` sets inclusive civil ranges of 1–90 days each. Baseline must end before intervention starts. Reissue to edit all dates; it clears opportunities and snapshots.
- `opportunities EXPERIMENT | BASELINE | INTERVENTION` declares integers 0–90 or `unknown`. Counts cannot exceed days in the window or fall below recorded completions. Weekly targets and window lengths never manufacture denominators. Changing opportunities clears dependent snapshots.
- `freeze EXPERIMENT` reads the selected habit once and freezes the recorded baseline dates. `compare EXPERIMENT` reads it once, freezes before if absent, saves a comparison and displays counts, denominators and limitations. A before capture can be retrospective; its timestamp is shown rather than presented as a pre-intervention measurement.
- `report EXPERIMENT` reopens the saved comparison without a source read. Baseline date changes are labeled stale against the frozen snapshot. Changed source label/target/provenance or absence from the permitted snapshot invalidates the current comparison. `reset-snapshot EXPERIMENT confirm` removes before/comparison evidence before an explicit new freeze.
- `edit EXPERIMENT title/intervention | TEXT`; `clear EXPERIMENT title/intervention/windows/opportunities/source confirm`; `create TITLE | INTERVENTION`. These edits invalidate dependent snapshots. Removing windows also removes opportunities.
- `help`; `list [page N]`; `show EXPERIMENT [page N rev R stamp HASH]`; `report EXPERIMENT [page N rev R stamp HASH]`; `export EXPERIMENT`; `delete EXPERIMENT confirm`.

Original toolbox UTC calendar labels remain literal dates, without midnight instants or caller-timezone shifts. Missing `days` is unknown; an explicit empty array is zero recorded check-ins. Unlogged days are not failures. Zero opportunities produces undefined adherence; impossible denominator/count combinations reject without changing the prior record. Comparisons are descriptive and make no causal claim. No command writes the habit store.

Source selection stores a compact ID/label and validated date/target/provenance metadata through `captureEvidence`; source body text is not retained. Full source shape is validated before projection. Saved selection and comparison fingerprints make changed source snapshots explicit. A failed or oversized read is a source-specific error, not a no-data result: use `/nobo-help tools habits list` and explicitly shorten/remove source records there, or retry when available. No arbitrary context kinds or sibling-store reads occur.

Version 1 schemas validate exact enums, canonical IDs/timestamps, source evidence, dates, window consistency and counts before every write, including deletion. Intended record snapshots are captured outside retries and asynchronous reads, then compared on each CAS attempt. Later edits/deletion win; unrelated record changes retry. Cancellation prevents late source results from saving. Saved-page continuations carry both revision and content stamps; habit-discovery pages reread once and also bind the complete source selection. Root lists recompute ten ID-ordered rows. Pipe/backslash literals use `\|` / `\\`; show pages and complete export recover all accepted fields.

Limits: 12 experiments, one source each, 100 adapter habits per read, source label text at most 2000 UTF-8 bytes plus at most 366 validated day labels. Title/intervention are 120/300 bytes. Each observation range is at most 90 days. Commands are 16000 bytes, ordinary replies 3500 JS units, complete record export 24576 bytes. State admission is 32768 and hard cap 49152 bytes. Admission projects required windows/opportunities/revision growth and, for each admitted source, maximum replacement metadata, frozen baseline and both observations. Byte limits may precede record counts. Replacement snapshots and mandatory observations remain available at accepted capacity. No eviction, expiry, history accumulation, cache or background job exists.

Budgets: zero generation/search, at most one habit read per explicit source command, eight logical state reads and four updates. `node --import tsx --test --test-concurrency=1 tests/agent-habit-experiments.test.ts` covers real toolbox habit commands through production services/adapters and runtime, denominator/date arithmetic, unknown/empty/zero, source edits/deletion, deferred cancellation/deletion, real CAS retries, malformed preservation, complete 100-source discovery, saturation and exact multipage retrieval. Fake backing storage only; no live service, Slack, Redis or deployment claim.
