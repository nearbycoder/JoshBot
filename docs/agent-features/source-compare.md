# Source comparison

Implemented locally, **unregistered and not deployed**. Parent integration and independent review remain required. This private feature aligns exact pasted source spans by user-created topic. Missing cells remain unknown, lexical differences never become contradictions, and agreement/disagreement are explicit user judgments rather than factual findings. NFKC/case/whitespace-normalized duplicate quotes are identified as non-independent corroboration; source independence is otherwise unknown.

Start `/nobo-help agent source-compare create Two onboarding studies`. Add two sources with `source COMPARISON add LABEL | PASTED_TEXT`, add `topic COMPARISON add Setup assistance`, and quote each with `quote COMPARISON TOPIC | SOURCE | EXACT_EXCERPT`. `compare COMPARISON` displays aligned cells and missing coverage. Labels use `label COMPARISON TOPIC | unknown|agreement|disagreement`; choose one token. Non-unknown labels need at least two current nonempty cells.

`edit`, `source ... edit`, `topic ... edit`, `quote-edit`, and `label` edit every accepted field. Source text/label edits clear its dependent quotes and reset affected topic labels; topic wording edits clear that row and reset its label. Quote changes/removals reset affected labels. Acknowledgements count discarded selections; there is no hidden stale history. `remove COMPARISON source|topic|quote|label CHILD_ID confirm` removes explicit input. Removing a source/topic also removes dependent cells. Help provides exact syntax and literal-pipe/backslash escaping.

Optional `synthesize COMPARISON` makes one text-model call. It selects/orders up to three topic highlights and exact current cells, as an **unsaved interpretation**. The model supplies only IDs and exact existing excerpts; strict validation rejects free prose, extra fields, unknown cells and fabricated quotes. Final prose is fixed composition around supplied titles, labels and quotes, so validated citations are never treated as proof of arbitrary generated claims. The digest retains unknown user labels and duplicate-evidence caveats. It does not select a true account or weighted winner. This deliberately constrained evidence digest is the optional summary.

Only selected topics/cells enter the model: input at most 16,000 UTF-8 bytes, instructions 4,000, accepted output 4,000 JavaScript units. Before calling the model, the three largest complete topic packets conservatively bound every allowed exact digest and JSON response. If that mandatory evidence/reply bound exceeds 3,500 reply units or 4,000 output units, synthesis refuses without a call; use deterministic compare or explicitly narrow selected cells/topics. The entire returned unsaved reply must also fit 3,500 units or is rejected. No retry, repair call, generated pagination, automatic save, source read or web fetch occurs. These output checks are post-generation, not provider token/spend caps. Provider failure leaves saved work intact. A content stamp plus revision is checked after generation, so same-revision changes at a revision ceiling also discard the stale result; cancellation prevents later writes.

`list [page N]`, `show COMPARISON [page N rev R]`, `export COMPARISON`, and `delete COMPARISON confirm` provide full retrieval/cleanup. `compare` and `show` continuations bind the originating revision and require page 1 after changes. Full pasted text stays in show/export even when comparison displays selected spans. Export is complete envelope JSON at most 24,576 UTF-8 bytes.

Strict schema version 1, canonical UUIDv4 IDs, six comparisons, up to five pasted sources and eight topics/40 unique cells each. Empty/one-source roots are preparation drafts; useful comparison/synthesis needs at least two sources. Sources allow 3,000 JavaScript units/12,000 UTF-8 bytes; quotes 600 units/2,400 bytes; titles/source labels 160 bytes and topic titles 200. State cap is 65,536 bytes, content admission 49,152. Actual serialized admission additionally projects maximum revision and all user-label growth into both state and export caps. Optional source/quote additions are content. Labels and confirmed removal remain possible above content admission while retaining hard/remaining-lifecycle guarantees. No expiry, eviction or global cache.

All mutation targets capture revision before CAS and check every retry, including labels, quote/source edits and removals. Same-record conflicts reject; unrelated changes retry safely. Corrupt state remains byte-for-byte intact even on confirmed delete. Budgets: one explicit generation, zero context/search, eight state reads/four updates, independent 32-attempt CAS bound. Matrix work is bounded by five sources/eight topics.
